# Phone Agent (Laptop Integration)

The `phone-agent` NixOS module integrates the laptop with the phone's Termux-based MCP server.
It provides HTTP MCP connectivity over Tailscale, automated file synchronization (ingest), and 
hardware-event bridging like proximity locking and network routing profile derivation.

For setup and configuration instructions, see [nixos/phone-agent/README.md](../nixos/phone-agent/README.md).
